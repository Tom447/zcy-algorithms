意思是：如果str2的字典序大于str1的字典序，那在0位置，说明即便加在了str1的0位置之前，得到的结果的字典序依然小于str1本身。

那么这种情况下就没有必要加在str1的前面

同样的道理，比如在i位置也是一样的。

![](images/WEBRESOURCE4b0211f9191341608566b66ebe5b3a26image.png)

要理解为什么当 str1 从位置 i 及之后的部分大于等于 str2 的字典序时，str2 没有必要插在 i 之前，我们需要深入分析字符串的字典序比较规则和插入操作的影响。

考虑以下情况：

- 假设 str1 从位置 i 开始的子串（记为 str1[i:]）的字典序大于等于 str2 的字典序。

- 这意味着 str1[i:] >= str2。

在这种情况下，如果我们将 str2 插入到 i 之前的任意位置，形成的字符串的字典序不会比直接保留 str1[i:] 更大。原因如下：

示例说明

假设 str1 = "abcde"，str2 = "bcd"，我们来分析一下：

1. 不插入的情况：

	- str1 本身已经是 "abcde"。

1. 插入到 i=0 的情况：

	- 新字符串变为 "bcdeabcde"，显然这个字符串的字典序小于 "abcde"。

1. 插入到 i=1 的情况：

	- 新字符串变为 "abbcdecdede"，这个字符串的字典序也小于 "abcde"。

1. 插入到 i=2 的情况：

	- 新字符串变为 "abcbcdcde"，这个字符串的字典序仍然小于 "abcde"。

1. 插入到 i=3 的情况：

	- 新字符串变为 "abcdcde"，这个字符串的字典序仍然小于 "abcde"。

1. 插入到 i=4 的情况：

	- 新字符串变为 "abcdebcd"，这个字符串的字典序仍然小于 "abcde"。

可以看到，只要 str1[i:] >= str2，无论 str2 插入到 i 之前的哪个位置，形成的字符串的字典序都不会超过直接保留 str1[i:] 的情况。

结论

**因此，当 ****str1**** 从位置 ****i**** 及之后的部分大于等于 ****str2**** 的字典序时，****str2**** 没有必要插在 ****i**** 之前，因为这样不会产生更大的字典序结果。我们应该继续寻找其他可能的插入位置，直到找到一个可以使字典序增大的位置，或者确定最佳插入位置为 ****i**** 或之后的位置。**

    public static String right(String s1, String s2) {
        if (s1 == null || s1.length() == 0) {
            return s2;
        }
        if (s2 == null || s2.length() == 0) {
            return s1;
        }
        String p1 = s1 + s2;
        String p2 = s2 + s1;
        String ans = p1.compareTo(p2) > 0 ? p1 : p2;
        for (int end = 1; end < s1.length(); end++) {
            String cur = s1.substring(0, end) + s2 + s1.substring(end);
            if (cur.compareTo(ans) > 0) {
                ans = cur;
            }
        }
        return ans;
    }

//    从 s1[first] 和 s2[0] 开始逐字符比较。
//    如果发现 s1[i] < s2[j]，说明从 i 开始，s1 的后缀已经 小于 s2。

//    所以设置 end = i，作为后续搜索的右边界。
//    举例：
//
//    s1 = "abcde", s2 = "bcd", first = 1
//    比较 s1[1]='b' vs s2[0]='b' → 相等
//    s1[2]='c' vs s2[1]='c' → 相等
//    s1[3]='d' vs s2[2]='d' → 相等

//
//    s1[3]='d' < s2[2]='e' → end = 3

//    对于每个插入位置 i，我们构造一个“前缀”字符串：
//    s1[first ... i-1]：从 first 到 i-1 的部分
//+ s2[0 ... j-1]：s2 的前 j 个字符（j 随 i 增加而减少）
//    这个“前缀”代表了从 first 开始到插入点附近的一段内容，用于比较哪个插入方式能让整体字符串更大。
//            🎯 为什么比较这个“前缀”？

//            5    0  "bcde" "" "bcde"

//            "bcdb" vs "bcd" → 大于 ✅ → 更新

//    意味着：在 s1 的位置 5（即末尾）插入 s2，得到 "abcde" + "bcd" 是最优的。

    public static int bestSplit(String s1, String s2, int first) {
        int N = s1.length();
        int M = s2.length();
        int end = N;
        for (int i = first, j = 0; i < N && j < M; i++, j++) {
            if (s1.charAt(i) < s2.charAt(j)) {
                end = i;
                break;
            }
        }
        String bestPrefix = s2;
        int bestSplit = first;
        for (int i = first + 1, j = M - 1; i <= end; i++, j--) {
            String curPrefix = s1.substring(first, i) + s2.substring(0, j);
            if (curPrefix.compareTo(bestPrefix) >= 0) {
                bestPrefix = curPrefix;
                bestSplit = i;
            }
        }
        return bestSplit;
    }

        public int[] sa;

        public int[] rank;

        public DC3(int[] nums, int max) {
            sa = sa(nums, max);
            rank = rank();
        }

        private int[] sa(int[] nums, int max) {
            int n = nums.length;
            int[] arr = new int[n + 3];
            for (int i = 0; i < n; i++) {
                arr[i] = nums[i];
            }
            return skew(arr, n, max);
        }

        private int[] skew(int[] nums, int n, int K) {
            int n0 = (n + 2) / 3, n1 = (n + 1) / 3, n2 = n / 3, n02 = n0 + n2;
            int[] s12 = new int[n02 + 3], sa12 = new int[n02 + 3];
            for (int i = 0, j = 0; i < n + (n0 - n1); ++i) {
                if (0 != i % 3) {
                    s12[j++] = i;
                }
            }
            radixPass(nums, s12, sa12, 2, n02, K);
            radixPass(nums, sa12, s12, 1, n02, K);
            radixPass(nums, s12, sa12, 0, n02, K);
            int name = 0, c0 = -1, c1 = -1, c2 = -1;
            for (int i = 0; i < n02; ++i) {
                if (c0 != nums[sa12[i]] || c1 != nums[sa12[i] + 1] || c2 != nums[sa12[i] + 2]) {
                    name++;
                    c0 = nums[sa12[i]];
                    c1 = nums[sa12[i] + 1];
                    c2 = nums[sa12[i] + 2];
                }
                if (1 == sa12[i] % 3) {
                    s12[sa12[i] / 3] = name;
                } else {
                    s12[sa12[i] / 3 + n0] = name;
                }
            }
            if (name < n02) {
                sa12 = skew(s12, n02, name);
                for (int i = 0; i < n02; i++) {
                    s12[sa12[i]] = i + 1;
                }
            } else {
                for (int i = 0; i < n02; i++) {
                    sa12[s12[i] - 1] = i;
                }
            }
            int[] s0 = new int[n0], sa0 = new int[n0];
            for (int i = 0, j = 0; i < n02; i++) {
                if (sa12[i] < n0) {
                    s0[j++] = 3 * sa12[i];
                }
            }
            radixPass(nums, s0, sa0, 0, n0, K);
            int[] sa = new int[n];
            for (int p = 0, t = n0 - n1, k = 0; k < n; k++) {
                int i = sa12[t] < n0 ? sa12[t] * 3 + 1 : (sa12[t] - n0) * 3 + 2;
                int j = sa0[p];
                if (sa12[t] < n0 ? leq(nums[i], s12[sa12[t] + n0], nums[j], s12[j / 3])
                        : leq(nums[i], nums[i + 1], s12[sa12[t] - n0 + 1], nums[j], nums[j + 1], s12[j / 3 + n0])) {
                    sa[k] = i;
                    t++;
                    if (t == n02) {
                        for (k++; p < n0; p++, k++) {
                            sa[k] = sa0[p];
                        }
                    }
                } else {
                    sa[k] = j;
                    p++;
                    if (p == n0) {
                        for (k++; t < n02; t++, k++) {
                            sa[k] = sa12[t] < n0 ? sa12[t] * 3 + 1 : (sa12[t] - n0) * 3 + 2;
                        }
                    }
                }
            }
            return sa;
        }

        private void radixPass(int[] nums, int[] input, int[] output, int offset, int n, int k) {
            int[] cnt = new int[k + 1];
            for (int i = 0; i < n; ++i) {
                cnt[nums[input[i] + offset]]++;
            }
            for (int i = 0, sum = 0; i < cnt.length; ++i) {
                int t = cnt[i];
                cnt[i] = sum;
                sum += t;
            }
            for (int i = 0; i < n; ++i) {
                output[cnt[nums[input[i] + offset]]++] = input[i];
            }
        }

        private boolean leq(int a1, int a2, int b1, int b2) {
            return a1 < b1 || (a1 == b1 && a2 <= b2);
        }

        private boolean leq(int a1, int a2, int a3, int b1, int b2, int b3) {
            return a1 < b1 || (a1 == b1 && leq(a2, a3, b2, b3));
        }

            int[] ans = new int[n];
            for (int i = 0; i < n; i++) {
                ans[sa[i]] = i;
            }
            return ans;
        }

package class45;

public class code02_CreateMaximumNumber {
//    为什么 maxIndex 的初始值是 size - get？
//    这是为了保证 maxIndex 的初始值是一个有效且安全的位置。
//    size - get 是 i 循环的起始点，也是在当前 get 值下，能够保证后面有足够元素（get 个）的最靠后的起始位置。
//    选择它作为初始 maxIndex，可以确保在后续比较中，如果前面的元素都更小，那么这个位置的元素就是当前范围内的最优选择。
   //dp[i][j] 表示i...上选取j个元素最大的起始位置
    public static int[][] getDp(int[] arr){
        int size = arr.length;
        int pick = arr.length + 1;
        int[][] dp = new int[size][pick];
        for (int get = 1; get < pick; get++){
            int maxIndex = size - get;
            for (int i = size - get; i >= 0; i--){
                if (arr[i] >= arr[maxIndex]){
                    maxIndex = i;
                }
                dp[i][get] = maxIndex;
            }
        }
        return dp;
    }

    public static int[] maxPick(int[] arr, int[][] dp, int pick){
        int[] res = new int[pick];
        for (int resIndex = 0, dpRow = 0; pick > 0; pick--, resIndex++){
            res[resIndex] = arr[dp[dpRow][pick]];
            dpRow = dp[dpRow][pick] + 1;
        }
        return  res;
    }

    public static int[] maxNumber1(int[] nums1, int[] nums2, int k){

        int len2 = nums2.length;
        if (k < 0 || k > len1 + len2) {
            return null;
        }

        int[] res = new int[k];
        int[][] dp1 = getDp(nums1);
        int[][] dp2 = getDp(nums2);
        // get1 从arr1里拿的数量
        // K - get1 从arr2里拿的数量
        for (int get1 = Math.max(0, k - len2); get1 <= Math.min(k, len1); get1++){
            // arr1 挑 get1个，怎么得到一个最优结果
            int[] pick1 = maxPick(nums1, dp1, get1);
            int[] pick2 = maxPick(nums2, dp2, k - get1);
            int[] merge = merge(pick1, pick2);
            res = preMoreThanLast(res, 0, merge, 0) ? res : merge;
        }
        return res;
    }

    public static int[] merge(int[] nums1, int[] nums2){
        int k = nums1.length + nums2.length;
        int[] ans = new int[k];
        for (int i = 0, j = 0, r = 0; r < k; r++){
            ans[r] = preMoreThanLast(nums1, i, nums2, j) ? nums1[i++] : nums2[j++];
        }
        return ans;
    }

    public static boolean preMoreThanLast(int[] nums1, int i, int[] nums2, int j){
        while (i < nums1.length && j < nums2.length && nums1[i] == nums2[j]){
            i++;
            j++;
        }
        return j == nums2.length || i < nums1.length && nums1[i] > nums2[j];
    }

    public static int[] maxNumber2(int[] nums1, int[] nums2, int k){

            int[] pick1 = maxPick(nums1, dp1, get1);

            int[] merge = mergeBySuffixArray(pick1, pick2);
            res = moreThan(res, merge) ? res : merge;
        }
        return res;

    public static int[] mergeBySuffixArray(int[] nums1, int[] nums2){
        int size1 = nums1.length;
        int size2 = nums2.length;
        int[] nums = new int[size1 + 1 + size2];
        for (int i = 0; i < size1; i++) {
            nums[i] = nums1[i] + 2;
        }
        nums[size1] = 1;
        for (int j = 0; j < size2; j++) {
            nums[j + size1 + 1] = nums2[j] + 2;
        }
        DC3 dc3 = new DC3(nums, 11);
        int[] rank = dc3.rank;
        int[] ans = new int[size1 + size2];
        int i = 0;
        int j = 0;
        int r = 0;
        while (i < size1 && j < size2){
            ans[r++] = rank[i] > rank[j + size1 + 1] ? nums1[i++] : nums2[j++];
        }
        
        while (i < size1){
            ans[r++] = nums1[i++];
        }
        while (j < size2){
            ans[r++] = nums2[j++];
        }
        return ans;
    }
    public static boolean moreThan(int[] pre, int[] last){
        int i = 0;
        int j = 0;
        while (i < pre.length && j < last.length && pre[i] == last[i]){
            i++;
            j++;
        }
        return j == last.length || (i < pre.length && pre[i] > last[j]);
    }

            for (int i = 0; i < n02; ++i) {
                if (c0 != nums[sa12[i]] || c1 != nums[sa12[i] + 1] || c2 != nums[sa12[i] + 2]) {

                    c1 = nums[sa12[i] + 1];

                } else {

            }

            } else {

            }
            int[] s0 = new int[n0], sa0 = new int[n0];
            for (int i = 0, j = 0; i < n02; i++) {
                if (sa12[i] < n0) {
                    s0[j++] = 3 * sa12[i];
                }
            }
            radixPass(nums, s0, sa0, 0, n0, K);
            int[] sa = new int[n];
            for (int p = 0, t = n0 - n1, k = 0; k < n; k++) {
                int i = sa12[t] < n0 ? sa12[t] * 3 + 1 : (sa12[t] - n0) * 3 + 2;
                int j = sa0[p];
                if (sa12[t] < n0 ? leq(nums[i], s12[sa12[t] + n0], nums[j], s12[j / 3])
                        : leq(nums[i], nums[i + 1], s12[sa12[t] - n0 + 1], nums[j], nums[j + 1], s12[j / 3 + n0])) {
                    sa[k] = i;
                    t++;
                    if (t == n02) {
                        for (k++; p < n0; p++, k++) {
                            sa[k] = sa0[p];
                        }
                    }
                } else {
                    sa[k] = j;
                    p++;

                        }
                    }
                }

        private void radixPass(int[] nums, int[] input, int[] output, int offset, int n, int k) {
            int[] cnt = new int[k + 1];
            for (int i = 0; i < n; ++i) {
                cnt[nums[input[i] + offset]]++;
            }
            for (int i = 0, sum = 0; i < cnt.length; ++i) {
                int t = cnt[i];
                cnt[i] = sum;
                sum += t;
            }
            for (int i = 0; i < n; ++i) {
                output[cnt[nums[input[i] + offset]]++] = input[i];
            }
        }

        private boolean leq(int a1, int a2, int b1, int b2) {
            return a1 < b1 || (a1 == b1 && a2 <= b2);
        }

        }

                ans[sa[i]] = i;
            }

        }

    public static int lcs1(String s1, String s2){
        if (s1 == null || s2 == null || s1.length() == 0 || s2.length() == 0) {
            return 0;
        }
        int row = s1.length();
        int col = s2.length();
        int[][] dp = new int[row][col];
        int max = 0;
        for (int j = 0; j < col; j++){
            dp[0][j] = s1.charAt(0) == s2.charAt(j) ? 1 : 0;
            max = Math.max(max, dp[0][j]);
        }

        for (int i = 0; i < row; i++){
            dp[i][0] = s1.charAt(i) == s2.charAt(0) ? 1 : 0;
            max = Math.max(max, dp[i][0]);
        }
//        dp[i][j]的含义是str1中以i结尾序列和str2中以j结尾的序列的公共自子串的长度
//            如果str[i] ！!= str[j], 就没有以i结尾的以j结尾的子串的所以就w为0
//        依赖关系dp[i][j] = str1[i] == str[j] ? dp[i-1][j-1] + 1 : 0

            }
        }

        return max;
    }
